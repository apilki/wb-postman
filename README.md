# @apilki/wb — Postman Collection

**Запросов: 306 · Собрано: 2026-11-20**

Готовая [Postman Collection v2.1](postman/collection.json) для **Wildberries
Seller API**: все 306 операций официальной спецификации, по папкам-модулям
(Общее, Товары, Заказы FBS/DBW/FBW, DBS, Продвижение, Коммуникации, Аналитика,
Отчёты, Финансы и т. д.).

Спецификация WB разбита на 22 самостоятельных документа (у модулей пересекаются
имена моделей), поэтому каждый модуль конвертируется отдельно и складывается
папкой в одну коллекцию. Полнота проверяется при сборке: число запросов = число
операций, иначе сборка падает.

Перезаписывается пайплайном apilki при каждом изменении API Wildberries.

## Как импортировать

1. Скачайте [`postman/collection.json`](postman/collection.json).
2. Postman → **Import** → выберите файл.
3. Заполните переменную коллекции `apiKey` — это ваш токен WB API
   (Личный кабинет продавца → Настройки → Доступ к API). Запросы используют
   заголовок `Authorization` с этим значением; публичные методы (ping, новости)
   работают и без него.
