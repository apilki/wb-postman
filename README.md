# @apilki/wb — Postman Collection

**Запросов: 300 · Собрано: 2026-11-25**

Готовая [Postman Collection v2.1](postman/collection.json) для **Wildberries Seller API**: 300 запросов — все операции официальной спецификации, по папкам-разделам.

Спецификация WB разбита на самостоятельные документы (у модулей пересекаются имена
моделей), поэтому каждый модуль конвертируется отдельно и ложится папкой в одну
коллекцию.

Полнота проверяется при сборке: число запросов = число операций в спецификации,
иначе сборка падает. Коллекция перезаписывается пайплайном apilki при каждом
изменении API — руками не редактируется.

## Как импортировать

1. Скачайте [`postman/collection.json`](postman/collection.json).
2. Postman → **Import** → выберите файл.
3. Заполните переменную коллекции `apiKey` — ваш токен WB API (личный кабинет продавца →
   Настройки → Доступ к API). Запросы несут заголовок `Authorization` с этим значением;
   публичные методы (ping, новости) работают и без него.
